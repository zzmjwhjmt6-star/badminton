# Badminton

Home-screen frame for a personal badminton court app.

- `index.html` shows the app (a Google Apps Script web app) inside a full-screen frame with its own icon,
  so it opens like a normal app on the phone's home screen.
- No URLs, tokens or data are stored in this repository. Each person opens their own private link
  (`…/#a=…&k=…`); the part after `#` never leaves their device.
